# SpooFX

بوابة مستقلة للحساب والمنتجات والمفاتيح. الواجهة عربية وإنجليزية، تدعم الجوال والوضعين الداكن والفاتح. لا تحتوي على منتجات أو عملاء أو مفاتيح تجريبية.

## الوظائف

- تسجيل دخول Google عبر NextAuth. صفحة `/portal` وواجهة `/api/portal` محميتان بجلسة الخادم.
- PostgreSQL يحفظ المنتجات والمفاتيح والتفعيل. يستطيع كل مستخدم رؤية المنتجات التي فعّلها على حسابه فقط.
- يستطيع المدراء المحددون بـ `ADMIN_EMAILS` (قائمة بريدية مفصولة بفواصل) إضافة المنتجات وتعديلها وإنشاء مفاتيح جديدة. يدعم `ADMIN_EMAIL` بريداً واحداً أيضاً. المفاتيح تُعرض مرة واحدة، ولا يُحفظ نصها؛ تُحفظ بصمة HMAC فقط.
- التفعيل عملية ذرية تمنع استخدام المفتاح مرتين، حتى عند وصول الطلبات في الوقت نفسه.
- `/api/health` يفحص اتصال قاعدة البيانات ويجهّز الجداول عند الحاجة، من دون عرض بيانات الحسابات.
- صفحة `/preview` القديمة تعيد المستخدم إلى صفحة الدخول، ولا توجد قوائم إدارة أو بطاقات وهمية.

## الإعداد

يتطلب Node.js 22 أو أحدث وقاعدة PostgreSQL. ثبّت الاعتماديات بـ `npm ci`، ثم عيّن متغيرات البيئة التالية في الاستضافة أو `.env.local` المحلي:

```dotenv
DATABASE_URL=postgresql://...
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
NEXTAUTH_SECRET=
NEXTAUTH_URL=https://your-domain.example
ADMIN_EMAIL=your-google-email@example.com
ADMIN_EMAILS=first@example.com,second@example.com
```

أنشئ `NEXTAUTH_SECRET` عشوائياً بطول مناسب، ولا ترفع `.env.local` أو أي قيمة سرية إلى GitHub. في Google Cloud أنشئ OAuth Client من نوع **Web application**، وأضف عنوان إعادة التوجيه `https://your-domain.example/api/auth/callback/google`. عند استخدام وضع اختبار OAuth أضف حسابات الاختبار إلى شاشة الموافقة. لا تستخدم مفاتيح المشروع المرجعي.

للموقع المنشور الحالي، عنوان إعادة التوجيه هو:

`https://abood-3d-production.up.railway.app/api/auth/callback/google`

أنشئت قاعدة PostgreSQL في مشروع Railway الخاص بالموقع، وربط `DATABASE_URL` بخدمة SpooFX. أضف قيم Google وقائمة بريد المدراء الخاصة بالموقع في Railway قبل استعمال تسجيل الدخول والإدارة. يعمل الموقع بأمان دونها، ويعرض رسالة واضحة بأن تسجيل الدخول لم يُهيأ بعد.

## التشغيل والتحقق

```sh
npm ci
npm run dev
npm run build
npm test
```

تتحقق الاختبارات من حماية الصفحات وواجهة البيانات، وحالة Google غير المهيأة، وطلب OAuth مع CSRF وPKCE، واستجابة واجهة الدخول على الجوال. لا تختبر تسجيل الدخول الكامل بحساب حقيقي قبل إضافة بيانات Google، ولا تنشئ منتجات أو مفاتيح اختبار في قاعدة الإنتاج.

على Windows تجنّب وجود `#` في مسار المشروع عند تشغيل بناء Next.js؛ يمكن استخدام مسار مختصر أو قرص افتراضي.
